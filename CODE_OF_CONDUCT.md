# Contributor Code of Conduct

## Our standard

Participation in this project is expected to be respectful, constructive and focused on the work. Contributors should assume good faith while remaining direct about technical problems.

Examples of expected behavior:
- Use welcoming, professional language.
- Explain criticism with reproducible evidence and technical reasoning.
- Respect different experience levels and reasonable design disagreements.
- Accept review feedback and keep discussions focused.
- Protect private information, credentials and user data.

Unacceptable behavior includes harassment, discrimination, threats, personal attacks, doxxing, deliberate disruption and publishing another person's private information without permission.

## Maintainer response

The project maintainer may edit or remove comments, close discussions, reject contributions or restrict participation for behavior that violates this policy. Reports should be sent privately to the repository owner through GitHub.

This policy applies to repository issues, pull requests, discussions, reviews and project-related communication.
