# World generation version 12

Newly created worlds use generator version 12. A saved world keeps the
`genVersion` in its manifest, so existing V1–V11 worlds continue to use their
original terrain, cave, ore, cactus, and tree-placement rules.

V12 includes the following versioned changes:

- Known-height V7/V8 biome queries classify using the supplied height and
  climate sampling, without running a second full surface-height sample. This
  API optimization does not change the biome selected for a generated column.
- A shallow V8 cave entrance may open the surface voxel when the voxel directly
  beneath it is already cave-positive. Flat worlds and ocean/shoreline columns
  remain protected.
- Cactus placement and height use a world-seeded, feature-salted coordinate
  hash.
- Ore vein walks count distinct visited coordinates rather than repeated
  random-walk visits. Ore stamping still replaces stone only and has a fixed
  attempt budget.
- Tree trunks and authored branch logs take priority over leaves from an
  overlapping canopy.
- The supported horizontal block-coordinate range is
  `-4,194,304 <= x,z < 4,194,304`. Chunks outside that range are generated as
  bedrock, block reads return bedrock, and block mutations outside the range
  are rejected. This keeps active chunk transforms and FastNoiseLite inputs
  well inside the single-precision integer-resolution limit while retaining
  half-block transform precision.

The range check is V12-only. V1–V11 save compatibility and generation output
are unchanged.
